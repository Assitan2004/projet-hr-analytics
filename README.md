# Analyse des Performances et de l'Absentéisme en Entreprise

Ce projet présente une analyse exploratoire des données (EDA) sur un jeu de données RH. L'objectif est d'étudier la répartition des performances, d'analyser l'absentéisme et d'identifier les valeurs atypiques (*outliers*) à l'aide de méthodes statistiques en Python.

## Objectifs
- Calculer les statistiques descriptives (moyenne, médiane, quartiles, écart-type).
- Visualiser les distributions des données via des graphiques (boxplots).
- Détecter les valeurs aberrantes en appliquant la règle mathématique des 1.5 * IQR.

## Outils et Bibliothèques
- Python
- Pandas (manipulation des données)
- NumPy (calculs statistiques)
- Matplotlib (visualisation)

## Structure du Projet
- `HRDataset_v14.csv` : Jeu de données source.
- `analyse_rh.ipynb` : Notebook contenant le code et les graphiques.
- `README.md` : Documentation du projet.
